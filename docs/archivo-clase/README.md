# Archivo de clase

Material de entregas anteriores de la asignatura (pruebas de caja negra del inicio de sesión, evidencias, guion de demostración y documentos de la versión «Intranet Privada FET» 1.x). Se conserva como referencia; no describe la versión actual de la plataforma.

Los scripts `.ps1` de esta carpeta se escribieron para la estructura anterior del proyecto y pueden necesitar ajustes de rutas.

La carpeta `pruebas-usuario-v2/` guarda los dos informes de pruebas de la versión 2.0.0 que luego se unificaron en `docs/pruebas-usuario/INFORME_PRUEBAS_USUARIO.md`: la ejecución por perfil y la sesión simulada, con sus PDF.
